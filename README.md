# Sniply AI

AI-powered URL Shortener and Analytics Platform built for Hackathon.

## Features

* URL Shortening
* Custom Aliases
* QR Code Generation
* Analytics Dashboard
* Campaign Management
* Click Tracking
* PDF Export
* Device Analytics
* Country Analytics

## Tech Stack

Frontend:

* React
* Vite
* Recharts

Backend:

* FastAPI
* SQLite

## Run

### Backend

```bash
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

### Frontend

```bash
npm install
npm run dev
```

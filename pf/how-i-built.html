How I Built This Portfolio

This portfolio was designed and developed from scratch using only HTML, CSS, and JavaScript. The goal was to create a clean, modern, and professional website that clearly represents my skills, learning mindset, and development approach.

Why I Chose HTML, CSS & JavaScript

I intentionally avoided frameworks to strengthen my fundamentals. Building this portfolio using vanilla technologies helped me understand layout systems, animations, DOM interactions, and performance considerations at a deeper level.

Project Structure & Organization

The project is structured into multiple pages with shared styles and scripts. This improves maintainability and reflects how real-world static websites are organized.

Animations & Interactions

Animations were implemented using CSS keyframes and JavaScript event handling. I focused on subtle transitions, hover feedback, and smooth motion to enhance user experience without overwhelming the content.

Accessibility & Performance

Accessibility and performance were important considerations. Keyboard navigation, reduced-motion support, and image lazy loading were added to ensure the site is usable, inclusive, and efficient.

What I Learned

Through this project, I improved my understanding of responsive design, UI consistency, modular CSS, JavaScript logic structuring, and how to present projects professionally for recruiters and interviews.
